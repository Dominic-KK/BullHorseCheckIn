# 🤖 牛马福音：智能打卡救命脚本

> **专为 996/007 牛马量身定制，妈妈再也不用担心我因忘打卡被扣绩效了！**

## 🎯 脚本简介

**「牛马打卡保命器」**——一款专治**金鱼记忆**、专防**老板扣钱**的神器！通过企业微信机器人，在您即将变身**忘打卡大冤种**时，准时送上爱的提醒~

> 💡 _90%的扣绩效都源于忘记打卡，而 100%的牛马都需要这个脚本！_

## ✨ 核心功能

### ⏰ **智能防呆提醒**

- **上班/下班双提醒**：告别“早上踩点冲、下班跑得快”的尴尬
- **±3 分钟容错**：考虑电梯排队、网络延迟等牛马常见问题
- **每日一次**：上下班提醒各一次，贴心不骚扰，避免被同事当成“烦人精”

### 💬 **消息高度自定义**

- **标题内容随便改**：从“打卡啦宝贝”到“再不打卡扣钱啦”任君选择
- **动态变量支持**：自动替换时间、星期，告别手动修改
- **上班/下班独立配置**：早上温柔唤醒，下班欢乐催促

### 📚 **~~文艺~~中二青年模式**

- **每日一言**：可选开启，在铜臭味的打卡中注入一丝~~文艺~~中二气息
- **名人名言**：让孔子、鲁迅等大佬为您打卡站台
- **自动出处**：装逼到位，文化人设不崩塌

### 👥 **精准@攻击**

- **@全员**：要死一起死，提醒全组牛马
- **@特定倒霉蛋**：专治组内著名“忘打卡大王”
- **静默模式**：偷偷提醒，深藏功与名

## ⚙️ 配置说明（懒人版）

### 🎯 基础设置

- **上班时间**：默认 9:00（可根据公司弹性调整）
- **下班时间**：默认 18:00（理想很丰满，现实...）
- **每日一言**：开关控制，提升逼格必备

### 💌 消息模板

支持变量：`{timeStr}`（当前时间）、`{weekday}`（周几）

**默认文案示例：**

```
🌅 上班打卡提醒 ⏰\n
⏰ 时间：{timeStr}\n
💼 今天是周{weekday}，搬砖时间到！\n
🎯 今日目标：搞钱！搞钱！搞钱！\n
```
